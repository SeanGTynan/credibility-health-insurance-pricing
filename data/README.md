# Data

This project uses publicly available data from the Medical Expenditure Panel Survey (MEPS).

## Main analysis

The main analysis uses the MEPS HC-252 Panel 27 Longitudinal Data File, covering 2022 and 2023.

The R script expects the downloaded Stata file to be named:

`h252.dta`

## COVID-19 robustness analysis

The robustness analysis uses the MEPS HC-245 Panel 24 Longitudinal Data File.

The R script expects the downloaded Stata file to be named:

`h245.dta`

## Data availability

The raw MEPS data files are not included in this repository. They can be obtained from the Medical Expenditure Panel Survey website.
